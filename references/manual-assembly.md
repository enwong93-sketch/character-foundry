# Manual placement and 360-degree review

Use this procedure with the accepted Hair, Head, and Body from steps 1–4. It adapts the head/neck seam and body/hair installation review procedures for coding agents. Use the available Blender scripting or control interface to place each part and obtain inspectable renders or screenshots.

1. **Set the body frame.** Import the accepted revisions into clearly named Body, Head, and Hair groups in one Blender scene. Record the source hashes, pose, transforms, and intended joins. Establish the body's scale and facing using the Master. Keep the body fixed after this.
2. **Fit the head and neck.** With hair hidden, compare front and side views. Rotate, move, and uniformly scale the head group together, including its neck and facial parts, using the neck axis, collar opening, and reference proportions. Keep the face geometry and expression data intact. A small overlap hidden inside a collar can provide a continuous join. Check the whole circumference before proceeding. Where geometry fits but skin differs, use [skin-tone matching](skin-tone-match.md).
3. **Fit the hair.** Use the accepted head as the anchor. Align the inside of the hair to the crown and scalp, then check temples, ears, nape, fringe, and any ornaments. Keep the intended hairline and the reference's deliberate eye coverage. Check both sides where long hair meets the shoulders, sleeves, or back. If a fit requires changing the accepted face or significantly deforming the hair, document the incompatible surface and revisit the affected input.
4. **Review each join with both sides visible.** Orbit the view around the join while keeping the model fixed. Start with overlapping views every 30° and add top, low, and close oblique views wherever an edge may be hidden. Check the neck underside and collar rim with the hair hidden, then review the final assembly with hair visible. Compare original-material and solid views at the same angle when a mark could be a gap, shadow, flipped face, or texture artifact.
5. **Record the result.** Flag gaps, visible poking through, exposed cut edges, floating roots or ornaments, unintended scalp exposure, double surfaces or flicker, and abrupt changes in shading or skin tone. Record PASS, FAIL, or UNVERIFIED for each interface sector with angle, image path, and observation. Missing or hidden sectors remain UNVERIFIED. After any correction, repeat the affected orbit. Save one Blender working file and the evidence only after checking the intended assembly. Static review covers the inspected pose.

The handoff includes the Blender file path, source hashes, final group transforms, before/after images for repairs or color changes, and separate results for geometry and appearance. If a join cannot be verified or repaired while preserving the design, report the exact location and retain the source parts for correction.
